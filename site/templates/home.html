Combat Simulator

A combat sandbox in Unreal Engine 5.8 where the fight is physics. A punch is a fist steered at a body; a hit is the momentum it carries, and it staggers or knocks down by the same rules as a thrown ball.

One developer, building it in public. It is an early prototype on a grey grid plane, with stand-in animation and no art yet.

How work moves

  1. A design question opens as a decision with an Issue anyone can comment on. When it is settled it gets a numbered record, including the options turned down. {{decisions}} so far.
  2. The work happens in a session. The session ends with a devlog entry and stills from the same fixed cameras, which is what the gallery is made of.
  3. A change to how the game plays is checked on a recording: the game plays itself through scripted scenarios and each segment is cut into a clip with the numbers it produced.
  4. A build goes to Steam's private development branch through one gated command, and is recorded on the builds page. {{builds}} so far.
